# Mouth Synth Privacy Policy

Public privacy policy for Mouth Synth, hosted on GitHub Pages.

- Japanese: https://dynarockpine.github.io/mouth-theremin-policy/
- English: https://dynarockpine.github.io/mouth-theremin-policy/en/

`index.md` contains the Japanese policy and `en.md` contains the English version. Keep both versions and their update dates consistent with the app implementation. The shared layout uses inline CSS and no JavaScript, external fonts, or third-party resource requests.

GitHub Pages publishes the repository root on the `main` branch. After an update, check the Pages build and both public URLs.
